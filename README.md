# Rivers Die Podcast — Website

Static website for The Rivers Die Podcast. Three pages (Home, Episodes, About), no build step.

## Hosting
Deployed on Vercel from this repo (`master` branch). Every push to `master` auto-deploys.

- Live: https://rivers-die-podcast.vercel.app
- Custom domain (pending): riversdiepodcast.com

## Structure
- `index.html` — Home (logo, platform links, latest episode)
- `episodes.html` — Episodes (auto-updating Spotify player + full episode archive)
- `about.html` — About the show and the hosts (Michael, Joe, Justin)
- `styles.css` — Shared styles
- `assets/logo.png` — Show logo

## Editing
Edit the HTML files, then commit and push to `master`. Vercel publishes the change automatically.
